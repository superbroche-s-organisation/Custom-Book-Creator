# Uploading V2.2.1 to MCreator

Upload these three **plugin** ZIPs as downloads, clearly labelled with the required MCreator version:

- `CustomBookCreator-MCreator2022.2-v2.2.1.zip`
- `CustomBookCreator-MCreator2024.4-v2.2.1.zip`
- `CustomBookCreator-MCreator2026.2-v2.2.1.zip`

Use [MCREATOR_DESCRIPTION.md](MCREATOR_DESCRIPTION.md) for the English feature description and [PATCH_NOTES.md](PATCH_NOTES.md) for the update announcement. The existing [website icon](../2.0.0/website-icon-512x512.png) remains unchanged.

Credit: **Superbroche**. Version: **2.2.1**. Link source code to the [GitHub release](https://github.com/superbroche-s-organisation/Custom-Book-Creator/releases/tag/v2.2.1). The sources ZIP is not an installable plugin.

State compatibility exactly as listed in the patch notes. The MCreator2026.2 package includes **NeoForge 1.21.1** and requires a compatible generator installed separately. The 2024.4 package fixes the nonfunctional Save buttons on both its Forge and NeoForge targets.

Only the three plugin ZIPs and sources ZIP are GitHub release attachments. Description, notes, icon and validation remain in the repository. These files are prepared for your manual upload; this workflow does not publish to mcreator.net.
