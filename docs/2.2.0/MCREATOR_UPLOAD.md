Use the three separately named **plugin** ZIPs as downloadable files and clearly label the required MCreator version. Do not upload the entire kit as the installable plugin.

- `CustomBookCreator-MCreator2026.2-v2.2.0.zip`
- `CustomBookCreator-MCreator2024.4-v2.2.0.zip`
- `CustomBookCreator-MCreator2022.2-v2.2.0.zip`

Use **MCREATOR_DESCRIPTION.md** for the English description, **PATCH_NOTES.md** for the release update and **website-icon-512x512.png** for the website icon (the existing MCreator plugin icon, enlarged, unchanged from V2).
