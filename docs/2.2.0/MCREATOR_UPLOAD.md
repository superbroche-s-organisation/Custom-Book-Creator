# Uploading V2.2 to MCreator

Use the three separately named **plugin** ZIPs as downloadable files and clearly label the required MCreator version.

- `CustomBookCreator-MCreator2026.2-v2.2.0.zip`
- `CustomBookCreator-MCreator2024.4-v2.2.0.zip`
- `CustomBookCreator-MCreator2022.2-v2.2.0.zip`

Use **MCREATOR_DESCRIPTION.md** in this directory for the English description, **PATCH_NOTES.md** for the release update and **docs/2.0.0/website-icon-512x512.png** in the repository for the website icon (the existing MCreator plugin icon, enlarged, unchanged from V2).

Credit: **Superbroche**. Version: **2.2.0**. Link sources to the GitHub repository/release. The source ZIP is not an installable plugin. GitHub releases attach only the three plugin ZIPs and the source ZIP; supporting documents and website resources stay in the repository.

List only the exact combinations in **VALIDATION.md**, not blanket support for Minecraft 1.17.1–26.2 or all loaders. These resources are for manual upload; publication on mcreator.net is not performed by the packaging script.
