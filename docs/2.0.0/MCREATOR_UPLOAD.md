# MCreator website upload kit — V2.0.0

Author: **Superbroche**

This kit is publication material. **Do not install the kit ZIP itself in MCreator.** Extract it first.

## Files to use

- `CustomBookCreator-MCreator2026.2-v2.0.0.zip`: the installable plugin to attach as the V2 download.
- `website-icon-512x512.png`: the existing Custom Book Creator icon, 512 x 512 pixels, for the website icon field.
- `MCREATOR_DESCRIPTION.md`: the complete English feature description. Copy its contents into the website editor, preserving headings and lists as supported.
- `PATCH_NOTES.md`: concise English V2 release notes for the update announcement.
- `CHANGELOG.md`: detailed English changes since 1.1.2-hotfix.
- `GUIDE.md`: installation and feature usage, including the compatibility matrix.
- `VALIDATION.md`: test results and validation limits.
- `CustomBookCreator-MCreator2026.2-v2.0.0-sources.zip`: source code for development or a separate source download, **not an installable plugin**.
- `SHA256SUMS.txt`: integrity hashes for the files in the kit, excluding this checksum file itself.

Suggested listing name: **Custom Book Creator**. Version: **2.0.0**. Author: **Superbroche**. Required MCreator version: **2026.2**.

The 1.20.x entries must be described as **experimental generator extensions requiring a separately installed, compatible generator**, not guaranteed complete support for every loader/version pair. Book-content translation is not included. Interface-language catalogs remain available.
