# Mode de saisie

- **FREE** : le joueur écrit librement du texte brut. Les choix prédéfinis sont masqués.
- **PRESET** : le joueur choisit une réponse dans la liste et ne peut pas écrire de texte libre. Prévoyez au moins un choix non vide.
- **BOTH** : le joueur peut écrire ou sélectionner une proposition, puis la modifier.

Pour un contrat, utilisez FREE pour une clause libre, PRESET pour des conditions imposées, ou BOTH pour des suggestions modifiables.

Tous les modes respectent la longueur maximale, la condition serveur autorisant l’écriture et la signature définitive. En PRESET, la valeur doit correspondre à un choix ; un texte par défaut absent de la liste est effacé.
