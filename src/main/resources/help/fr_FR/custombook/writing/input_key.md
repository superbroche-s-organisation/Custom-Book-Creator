# Clé permanente du champ

Cet identifiant permanent (par exemple `field_12ab34`) est créé automatiquement et affiché en lecture seule.

Le texte saisi par un joueur est enregistré sur son exemplaire du livre sous cette clé. Renommer la zone, la déplacer ou réordonner les pages conserve ce lien. Deux exemplaires du même livre peuvent contenir des réponses différentes.

Conservez la clé après avoir distribué le livre. La modifier dans les données source, ou supprimer la zone puis en créer une nouvelle, crée un autre champ : le texte enregistré avec l’ancienne clé ne sera pas affiché dans la nouvelle zone. Ce n’est ni une clé de traduction Minecraft ni une variable de procédure. Chaque zone doit avoir une clé unique ; le plugin résout les doublons lors de la sauvegarde.
