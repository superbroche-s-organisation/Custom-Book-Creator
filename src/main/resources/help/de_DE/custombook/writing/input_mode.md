# Input mode

Choose how players fill in this zone:

- **FREE**: players type their own plain text. Predefined choices are not shown.
- **PRESET**: players choose one of the predefined lines. They cannot type arbitrary text. Add at least one non-empty choice to make this mode useful.
- **BOTH**: players can either type text or select a predefined choice, then edit it.

For a contract, use FREE for a custom clause, PRESET for approved terms, or BOTH for suggested terms that players can adapt.

All modes respect Maximum characters, the book's server-side writing permission and permanent signatures. Changing the mode does not bypass those restrictions. PRESET values must match one of the choices; a default value that does not match is cleared.
