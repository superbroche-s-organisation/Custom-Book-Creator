# Default plain text

Initial content displayed in a writing zone before a player saves their own value. Leave it empty for an initially blank zone. For example: `I agree to deliver 10 emeralds.`

This is actual initial content, not placeholder text. Once a player has saved this field on a book item, their saved value (including an empty value) takes precedence. Changing the default affects unfilled fields, not text already saved by players.

The content is plain text: formatting tags such as [b] and [color=...] are not interpreted. It is limited by Maximum characters (up to 1,024 characters per zone). The entire book can store up to 4,096 characters across its writing zones.

In PRESET mode, the default must exactly match one of the predefined choices; otherwise it is cleared. In FREE and BOTH modes, players may edit it if writing is allowed and the book has not been signed.
